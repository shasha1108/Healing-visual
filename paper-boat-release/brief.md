## 1. 概念种子

> 表面需求："玻璃瓶里放纸船"。概念锚点：

**放手不是失去——放走的东西没有消失，它们在你看得见的地方发光。**

用户看完记住的不是瓶子，是"我放走的船变成了河灯"。告别被可视化成一件温柔的事：船走了，灯留下。这决定了一切下游选择——逃逸不是消失动画，是**位置从瓶内转移到背景**；背景不是装饰，是"放行结果"的陈列面。

## 2. Name the Movement（内部北极星，不对外）

**「回头一停」**

每只纸船漂到瓶口时会停半秒、轻轻晃一下，再离开——像回头看了一眼。这个反预期瞬间是全作的记忆点（对应 eternal-bloom"伸手花会躲"、bottled-cosmos"星辰定居背景"的同款设计意图），所有动画曲线、音效 timing 都为这半秒服务。

## 3. 一句话概念（种子表检验）

| 一句概念 | 它是什么 | 具体描述 |
|---|---|---|
| 放行的纸船 | 会发光的告别 | 一只玻璃瓶里折着七只纸船；打开瓶塞，它们一只只漂进夜河变成河灯，每只离开前都会回头看一眼 |

## 4. 选型（对照 glass-jar-playbook）

| 决策点 | 选择 | 理由与出处 |
|---|---|---|
| 容器形态 | **药剂瓶**（窄口圆底，倾斜摆放） | 主题是"从唯一出口离开"，窄口=唯一的门；完整实现直接抄 `glass-bottle-kit.md`，瓶形/innerR/三 pass/绳塞/TILT 全部复用 |
| 边界路线 | **路线 A：innerR 精确边界** | 纸船要沿颈部收束出瓶，必须精确边界；逃逸态跳过 yTop 只做颈部收束（kit 已踩过的坑，直接继承修复形态） |
| 高光方案 | **V1：填充高光带 + blur(12k)** | 夜河深色背景 + 厚玻璃药剂瓶；硬边=布条铁律生效 |
| 交互内核 | **双世界打通（开塞逃逸）** 为主；**clamp 吸附轻摇**为次 | 主内核抄 kit 逃逸系统；次反馈=触摸瓶身时瓶内纸船轻轻摇晃 |
| 渲染器 | p5.js Canvas 2D，不嵌 3D | 纸船是 2D 剪影+光点，不需要 WebGL |
| 像素/平滑 | **平滑系**（非像素网格） | 药剂瓶系血统（drift-bottle/bottled-cosmos 同款），水光需要连续渐变 |

## 5. 世界设定

### 瓶内（局部坐标系，kit 约定：原点=路径原点，+y 向下）

- **七只纸船**：折纸剪影（3-4 个三角面拼出，受光面暖白 `rgba(255,244,214)`、背光面 `rgba(214,188,148)`），漂浮在瓶底浅水上，随水波轻晃 + 相互极缓碰撞换位
- **船舱灯火**：每只船中心一点暖光（同路径双描边发光：芯 2px + 晕 6px，lighter）——船是"还没放出去的灯"，这是形态与主题的统一：纸船即河灯的幼体
- **浅水层**：瓶底一层夜水（深蓝渐变 + 水面细波线），纸船吃水线处一圈微弱反光

### 瓶外背景（屏幕空间）

- **夜河**：深色纵向渐变（近瓶处略亮），水面 = 瓶后一层缓慢平移的波光带（3-5 条不同速度/透明度的正弦波线，视差）
- **远岸**：极淡的剪影线 + 两三粒固定暖光（别处的灯，告诉用户"船要去的地方存在"）
- **河灯层（放行的结果）**：逃逸纸船过瓶口线 → 转屏幕坐标 → 减速漂向远处 → **定居为背景河灯**（bgStars 机制换皮：暖光点 + 椭圆水面倒影 + 呼吸闪烁），会话内不消失

### 两个世界打通

- 开塞 → 瓶口光束（kit 楔形渐变，暖色调）→ 纸船依次（不是同时！每 1.2-2s 一只）向瓶口加速 → **瓶口停顿 0.4-0.6s + 轻晃（回头一停）** → 越线转屏幕坐标 → 漂远定居
- 关塞 → 剩余纸船恢复瓶壁约束；瓶底纸堆慢慢再折出新船（每 20-30s 一只，折的过程可见：三角面逐帧立起）——**世界守恒，可无限重访**
- 背景河灯在会话内长明；刷新即天亮（"只亮到刷新之前"——限制转诗意，已验证能成标题）

## 6. 交互设计

| 层级 | 交互 | 反馈 | 内核 |
|---|---|---|---|
| 主反馈 | **点击瓶塞**：开合（corkAnim 缓动） | 开=放行开始；关=停止 | kit 软木塞开合全套 |
| 次反馈 | 触摸/划过瓶身 | 瓶内纸船轻摇（clamp 吸附：触点钳进水面矩形，不做命中判定）；敲玻璃泛音 | clamp 吸附（playbook §五.1） |
| 环境反馈 | 无操作时 | 河灯呼吸闪烁、波光视差平移、瓶身极缓摇摆（±0.02） | 调光器标量驱动 |
| 隐藏反馈 | 点击背景里的河灯 | 那盏灯亮一下、荡开一圈涟漪——"它还认得你" | 涟漪环（sealPulse 机制换皮） |

**反预期记忆点**：瓶口的"回头一停"——逃逸轨迹在 `y < -158k` 越线前插入 0.4-0.6s 悬停 + 摇摆，配一声比其它音低半度的铃音。**这是全作唯一允许破坏流畅感的地方。**

**音频**（Web Audio，手势内 resume）：低音 drone（水声质感，低通）；开塞一声软木轻响；每只船离瓶一声玻璃泛音铃，七只船按五声音阶顺序拾音（tidal-moon-moss 机制）；定居河灯时极轻的一声"叮"。

## 7. 视觉方向

- **色板人格**：「夜河暖灯」——夜蓝 `#0b1226/#16224a` 为底，暖纸金 `#ffe9b8/#ffb85c` 为魂；冷暖比 ≈ 8:2，暖色只给纸船/河灯/瓶口光束
- **提亮纪律**（kit 信息流参数直接继承）：底色 ≥rgba(20,27,58,0.82) 档、玻璃压暗 ≤0.32、粒子/灯火呼吸底值 ≥0.3、暗角 ≤0.34；idle 首帧必须能当信息流封面
- **倾斜摆放**：TILT=-0.5 + 摇摆 ±0.02（kit 原值）；交互坐标 toLocal 逆旋转

## 10. 验证清单（合并 playbook §九 + 本作特定）

**idle 态**
- [ ] 首帧可当封面：瓶身轮廓、暖光点、瓶口金丝绳在小屏缩略图可辨
- [ ] 高光带读作"光"；瓶底厚度与收口贴合；塞子与瓶口嵌入

**交互态**
- [ ] 开塞后纸船**依次**（非同时）沿颈部收束出瓶；每只都有可感知的瓶口停顿
- [ ] 越线后进入背景、减速、定居为河灯且**不消失**；关塞后无穿壁
- [ ] 触摸瓶身纸船轻摇、命中准确（toLocal 逆旋转生效）
- [ ] 点击背景河灯有回应（涟漪+提亮）

**世界守恒**
- [ ] 放空后关塞，瓶内 20-30s 折出新船（过程可见）
- [ ] `?seed` 两次截图一致；`?opencork=1` headless 截图可见河灯终态

**边界（skill 路由纪律）**
- [ ] 本作是可重访小世界（船可再生、灯可回应），**不做**一次性情绪交接仪式：不加"写下告别的话"输入框、不做"放完即终态"——那会路由到 healing-space。情绪是轻量的、可重复的。

## 11. 迭代顺序（h5-p5js-craft-lessons 纪律）

1. **阻断性**：瓶子可见/逃逸能出瓶/坐标变换正确（headless 截图逐态验证）
2. **识别度**：纸船一眼认出是折纸船（三角面结构差异，不是色块）；"回头一停"在录屏里可感知
3. **完成度**：波光视差/音频层次/河灯呼吸节奏/冷暖比打磨

**二次精修纪律**：初稿完成后只删减、微调、加强关联，不加新元素。
